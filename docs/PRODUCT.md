# 製品構想: Passive Personal Mapping

## 一文の定義

**現実空間を普通に探索するだけで、自分が実際に知った部分が、自分専用の地図として残り育っていくアプリ。**

## 解こうとしている問題

一般的な地図は「世界がどうなっているか」を最初から表示する。一方、探索の面白さや実用性は「自分がどこを知り、どこをまだ知らないか」にある。

既存の訪問履歴アプリは既存地図を正本にし、自分の軌跡を重ねる。GISは地図を作れるが、現地で専門的な作図操作が必要になる。屋内スキャンは詳細な平面図を作れるが、カメラやLiDARを構えながら歩く必要がある。

この製品は、次の逆転を行う。

```text
一般的な地図
世界の地図（正本） + 自分の履歴（付加情報）

本製品
自分の探索証拠（正本） + 必要なら既存地図（補助レイヤー）
```

## コア価値

### 1. 未知が、自分の知っている空間へ変わる

地図を見ることではなく、探索の結果として地図が形成されること自体を楽しめる。

### 2. 一度の探索が、そのまま残る

同じ道を2回、3回通る必要はない。初回で経路を作り、再訪は精度向上や接続確認に使う。

### 3. 探索を邪魔しない

開始後はスマホをしまう。画面を見続ける、カメラを構える、線を手で引くことを通常フローにしない。

### 4. 精密測量ではなく、使える個人地図

最初に狙うのは、壁や道幅が正確な図面ではない。「どこを通り、何を見つけ、どこが未探索か」を思い出し再利用できる地図である。

## 対象となる状況

場所カテゴリで製品を分けない。次はすべて同じ概念の例である。

- 初めて歩く街区や路地
- 大きな公園、施設、会場、学校、会社敷地
- 建物、地下、複数階の空間
- 自然地帯、キャンプ場、山林、河原
- 地図に載らない通路や一時的な会場

対象は「山」や「屋内」ではなく、**ユーザーにとってまだ把握されていない空間**である。

## 基本ユーザージャーニー

```text
1. 新しい探索を始める
2. スマホをしまう
3. 普通に歩く
4. 気になった時だけ発見を記録する
5. 探索を終える
6. 自分の白紙地図に、今回知った経路と発見が現れる
7. 次回、その地図から続きを探索する
```

## MVPの成功条件

最初の製品判断は、屋内自動平面図の精度ではなく次で行う。

- 開始操作が迷わず短い
- スマホをしまった状態で記録が続く
- 一回の外出から見返したくなる地図が得られる
- 発見入力が探索を中断しすぎない
- 位置誤差がある場合でも、何が確かで何が推定か理解できる
- 既存地図を表示しなくても「自分の探索記録」として意味がある

## 非目標

- Google Mapsの代替ナビゲーション
- 測量精度の地図、法的・安全上の保証
- 建物の壁・部屋をポケット内スマホだけで自動確定
- 常時カメラ撮影
- 地図共有SNSの先行実装
- ゲーム継続率だけを目的にした位置情報収集

## 将来のゲーム要素

ゲーム要素を上に載せ、交換可能にする方針は妥当である。

コアは次のイベントを発行するだけにする。

- exploration.started
- position.accepted / position.rejected
- marker.added
- segment.discovered
- exploration.ended

ゲーム拡張は読み取り専用スナップショットから、Fog、探索率、実績、物語、収集物などの派生レイヤーを返す。ゲームが変わっても生の探索記録や個人地図は残る。
