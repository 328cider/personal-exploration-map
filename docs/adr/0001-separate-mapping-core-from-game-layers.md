# ADR 0001: マッピング・コアとゲームレイヤーを分離する

- Status: Accepted
- Date: 2026-08-07

## Context

将来、Fog、探索率、実績、収集、物語などを追加したい。一方、ゲーム要素は変更・置換されやすく、位置データの真実や地図保存形式まで巻き込むと、地図アプリとしての価値が失われる。

## Decision

mapping-coreは探索、サンプル品質、座標変換、経路、発見、イベントだけを扱う。

ゲームはイベントと読み取り専用MapSnapshotを受け取り、派生overlayと独自状態を返すextensionとする。

## Consequences

- ゲームなしでアプリが完成する
- 複数テーマを差し替えられる
- ゲームのルール変更で過去地図を移行しなくてよい
- extension APIの設計が必要になる
- コアから直接「経験値」などを参照できない
