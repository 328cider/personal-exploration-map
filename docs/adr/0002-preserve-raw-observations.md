# ADR 0002: 生の観測を保持し、地図を派生物にする

- Status: Accepted
- Date: 2026-08-07

## Context

GNSSとPDRには誤差、欠落、異常ジャンプがある。初期のフィルタ規則は後で改善される。処理済みの線だけを保存すると、誤判定の修正や別アルゴリズムの比較ができない。

## Decision

すべての位置サンプルをraw observationとして保持する。受理・除外理由、ローカル投影、簡略化経路、探索領域は派生物とする。

## Consequences

- アルゴリズムを改善して再構築できる
- 不確実性の根拠を説明できる
- 保存量は増える
- プライバシー上、rawデータの保護と削除がより重要になる
