# ADR 0003: 白紙地図を既定とし、既存地図は補助レイヤーにする

- Status: Accepted
- Date: 2026-08-07

## Context

既存地図を常に表示すると、FogアプリやGPSロガーとの違いが薄れ、「自分が知った世界」という体験を検証できない。またGPSのないローカル空間では既存地図を前提にできない。

## Decision

レビュー画面の既定は白紙キャンバス上の自分の経路と発見にする。既存地図は将来、任意に重ねる補助レイヤーとして追加する。

## Consequences

- 製品仮説を直接検証できる
- 屋内 / 局所座標と同じレンダラーを使える
- 地理的文脈が必要な利用者には不便な場合がある
- 将来、任意のbasemap toggleを検討する
