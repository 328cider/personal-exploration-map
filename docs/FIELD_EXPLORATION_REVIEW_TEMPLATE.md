# 実探索レビュー・テンプレート

更新日: 2026-08-09
対象: Issue #4 / Personal Exploration Map M0

## 使い方

このテンプレートは、実地試験後に**端末から自動取得できない主観評価だけ**を残すためのものです。

端末、Android、開始・終了時刻、電池、権限、位置精度、sample gap、callback、エラーなどはUSB Field-test bundleから回収します。ここへ転記しません。

1回の探索データから`不確実性 / 通過セル / 軌跡`を切り替えて比較します。表示方式ごとに歩き直しません。

## プライバシー

このMarkdownへ次を記載しません。

- 正確な住所・座標
- PersonalMap / ExplorationSession ID
- 地図名や発見メモ本文
- 特定可能な地図画像

通常共有するのは`coordinate-free-diagnostics.txt`と、この主観評価だけです。USB回収で生成されるraw ZIPには正確な移動履歴が含まれるため、PCローカルに保持し、公開Issueや通常のチャットへ添付しません。
